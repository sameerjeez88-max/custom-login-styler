Beautify your WordPress login page with custom background colors, form styles, and your own logo.

== Description ==

Custom Login Styler allows you to completely transform the default boring WordPress login screen. 

**Features:**
* Toggle Enable/Disable
* Change Page Background Color
* Change Form Background Color
* Change Submit Button Color
* Upload/Add Custom Logo via URL
* Built-in WordPress Color Picker for easy selection
* Clean and lightweight code

== Installation ==

1. Upload the `custom-login-styler` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to the **Login Styler** menu in your WordPress admin dashboard.
4. Customize your colors and logo, then hit Save.

== Frequently Asked Questions ==

= Does this plugin modify core WordPress files? =
No, it uses standard WordPress hooks and filters to safely override the CSS on the login page.
